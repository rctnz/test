S1-3ศุภิสรายิ้มค้าง นิ้วลอยอยู่เหนือคีย์บอร์ดไม่กล้ากดศุภิสราได้ค่ะ... สักครู่นะคะ (กระซิบ) กดเลขอะไรเนี่ย

2. ช่วงโมชันกราฟิก ประมาณ 7:25

แนวทางภาพรวมของโมชัน (ใช้ทุกซีน)

  • หน้าต่างเทอร์มินัล: พื้นดำ ตัวอักษร monospace สีขาวนวล วางกลางจอ มีขอบโค้งและแถบหัวหน้าต่าง ข้อความในเทอร์มินัลต้องตรงกับโปรแกรมจริงทุกตัวอักษร (เป็นภาษาอังกฤษตามโปรแกรม)
  • การพิมพ์: สิ่งที่ผู้ใช้พิมพ์ให้ขึ้นทีละตัวอักษร สีเหลือง แล้วมีไอคอน Enter กระพริบหนึ่งครั้ง
  • ไฮไลต์: กรอบสีเหลืองวาดล้อมบรรทัดที่กำลังพูดถึง ถ้าเป็นข้อความเตือนหรือปฏิเสธใช้กรอบแดง ถ้าสำเร็จใช้กรอบเขียว
  • ป้ายผู้พูด: มุมล่างซ้ายมีวงกลมรูปผู้พูด + ชื่อ + บทบาท ("พี่เลี้ยง" / "น้องใหม่" / "ผู้บรรยาย") เปลี่ยนทุกครั้งที่เปลี่ยนคนพูด เวลาน้องใหม่ถามให้ป้ายเด้งมาจากมุมล่างขวาแทน จะได้แยกออกว่าเป็นคนถาม
  • แถบนำทาง: ด้านบนจอมีแถบบอกตำแหน่ง เช่น Main menu > 1 Book management > 1 Add book อัปเดตทุกซีน
  • คำแปลไทย: ข้อความสำคัญในโปรแกรมที่เป็นอังกฤษ ให้มีคำอธิบายไทยสั้น ๆ ลอยข้างกรอบไฮไลต์ (ระบุไว้ในแต่ละซีน)
  • การเปลี่ยนเมนูใหญ่: ขึ้นการ์ดคั่น 1.5 วินาที เลขเมนูตัวใหญ่ + ชื่อเมนู + ชื่อพี่เลี้ยงที่สอน
  • ข้อมูลตัวอย่างที่ใช้ทั้งเรื่อง: รหัสนักศึกษา 69000000001 หนังสือที่เพิ่มใหม่ Clean Code ของ Robert C. Martin ห้อง R001 เวลา 13

ค่าที่เขียนในวงเล็บแหลม เช่น <รหัสหนังสือใหม่> ขึ้นกับข้อมูลจริงในไฟล์ตอนอัด ต้องแทนด้วยค่าที่โปรแกรมแสดงจริง ดูรายการเตรียมข้อมูลในหัวข้อ 4
